# Haier AC Service Center Dashboard

## Project Overview
This project is an interactive Microsoft Excel dashboard developed to analyze the performance of a Haier AC Service Center.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Dashboard Features
- Total Service Requests
- Service Revenue Analysis
- Booking Status
- Pending Services
- Technician Performance
- Monthly Service Trend
- Service Type Comparison
